## 🏪 درباره پروژه

روغنکده رئوف یک وب‌سایت فروشگاهی مدرن و ریسپانسیو برای فروش محصولات سنتی و طبیعی است. این پروژه توسط سهیل جلال احمدی طراحی شده و به صورت اوپن سورس و رایگان منتشر شده است.

این فروشگاه از سال ۱۳۷۵ فعالیت خود را آغاز کرده و اکنون نسل سوم این خانواده، با همان روش‌های سنتی و نظارت بهداشتی مدرن، محصولات را به مشتریان می‌رساند.

---

## ✨ ویژگی‌ها

- **سیستم سبد خرید کامل:** افزودن و حذف محصولات، ذخیره‌سازی در `localStorage`، محاسبه تخفیف، سیستم Toast
- **طراحی مدرن و ریسپانسیو:** واکنش‌گرا برای موبایل، تبلت و دسکتاپ، انیمیشن‌های نرم، منوی موبایل کشویی
- **فیلتر و جستجو:** ۱۳ دسته‌بندی، فیلتر قیمت، مرتب‌سازی (جدیدترین، ارزان‌ترین، گران‌ترین، پرتخفیف‌ترین، پرفروش‌ترین)، نمای گرید و لیست
- **صفحات کامل:** صفحه اصلی، فروشگاه، محصول، درباره ما، تماس با ما

## 🛠️ تکنولوژی‌ها

HTML5، CSS3، JavaScript ES6+، Tailwind CSS 4.3.3، فونت وزیرمتن، Lucide Icons

## 🚀 نصب و راه‌اندازی

```bash
# کلون کردن پروژه
git clone https://github.com/soheilja/raoufoil.ir.git
cd raoufoil.ir

# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه
npm run dev
```

سپس فایل `index.html` را در مرورگر باز کنید یا از سرور محلی استفاده کنید:
```bash
python -m http.server 8000
# یا
npx serve
```

## 🛒 سبد خرید

سیستم سبد خرید کاملاً کلاینت‌ساید با JavaScript خالص پیاده‌سازی شده است:
- افزودن، حذف و تغییر تعداد محصولات
- ذخیره‌سازی در `localStorage` (کلید: `raouf-cart-v1`)
- محاسبه خودکار جمع کل و تخفیف
- دراور کشویی با نمایش قیمت واحد و کل
- پیام‌های Toast برای اعلان‌ها

## 🎨 طراحی

- **پالت رنگی:** سبز تیره (`#002F18`) و طلایی (`#E4B027`) با پس‌زمینه کرم
- **فونت:** وزیرمتن 33.003، جهت متن راست‌به‌چپ (RTL)
- **کامپوننت‌ها:** دکمه طلایی، کارت محصول با هاور، کاروسل، Toast، Badge
- **انیمیشن‌ها:** fadeUp، toastIn، pop، reveal
